# Neural Network Learning Roadmap

# Phase 1 -- Practice Datasets

MNIST (using the MLP)

---

# Phase 2 -- Convolutional Neural Networks

Learn:

-   Convolution
-   Filters/Kernels
-   Feature Maps
-   Padding
-   Stride
-   Pooling

Then solve MNIST again and compare the results with your MLP.

# Phase 3 -- Transformers

Learn:

-   Embeddings
-   Positional Encoding
-   Self-Attention
-   Multi-Head Attention
-   Feed-Forward Networks
-   Residual Connections
-   Layer Normalization

---

# Phase 4 -- Tiny LLM

Build progressively:

1.  Character-level language model
2.  Shakespeare text generator
3.  Small story generator
4.  Tiny code completion model
